# 半導体・メモリー定点観測｜追加仕様「セクターの状態」（sector_health v1.1、config 1.6）

作成 2026-11-10。v1.1（同日）：底の局面（washout.phase）と 2.4b「3条件がそろった後の経過」を追加、「外れなし」の表現を訂正。実装：`build_health.py`（出力 `sector_health.json`、履歴 `history_health.csv`）、`build_signals.py`（前日比の変化点）。
設定：`config.json` の `sector_health`。プロンプト：日次 v1.7 の 0節、判定 v6.7 の 4d節と引継ぎ `SECTOR_HEALTH`。

## 0. 目的と位置づけ

「半導体セクター自体が強いか弱いか」を、**指数（SOXX）・中身（約40銘柄）・相対力（他のテクノロジーとの比較）**の3つから毎日機械的に出す。
きっかけは X の @MARU_X の SNDK チャート（指数・XLK・大分類・業種の4段の帯が2026年9月末にそろって赤に変わった）。
これをセクター全体に当てはめ、15年（2011〜2026年11月）で検証して、効いたものだけを残した。

- **採点（S1〜S5・D1〜D6・A〜X）は変えない。** 表示・引継ぎ・変化点シグナルの追加だけ。3回のレポートで並べて見てから、採点に入れるかを決める。
- **売買の合図ではない。** 乗り換え（帯が全部赤なら半導体から降りる）は15年の検証で持ちっぱなしに負けた（下の3節）。レポートでは「描写」として書き、「買え」「売れ」とは書かない。
- 公式のステージ分析（細区分 1A〜4B-）は米国株指標チェック側（market-data E6.2・E6.3）が正本。ここでは簡易版だけを計算し、公式の値は signals.json から転記する。

## 1. 定義（build_health.py）

価格は close（分割調整済み・配当非調整）。母集団は `breadth_sets.semis_broad`（42銘柄）。米国の取引日だけで計算する。

| 項目 | 定義 |
|---|---|
| 簡易ステージ | 上昇中（stage2相当）＝終値 > 150日線 かつ 150日線が20本前より上。下落中（stage4相当）＝終値 < 150日線 かつ 150日線が20本前より下。150日線が無い銘柄（上場1年未満）は分母に入れない |
| 中身（breadth） | 20日線・50日線・150日線（30週線）の上にいる割合、上昇中／下落中の割合と差（net）、13週高値・安値の割合、均等加重の対SOXX 13週 |
| 判定ラベル | market-data E6.3 と同じ順番：**弱い**＝下落中 40%以上 → **悪化中**＝4週前より下落中が 10pt以上増、または上昇中が 10pt以上減って下落中が減っていない → **健全**＝上昇中 50%以上かつ下落中 20%未満 → **改善中**＝上昇中が 10pt以上増かつ下落中が増えていない → それ以外 **どちらとも言えない** |
| 危険の目安（risk） | 3条件のそろい数（0〜3）：①判定が悪化中か弱い ②SOXX が 150日線の下 ③市場（SPY）と比べた13週の成績がマイナス |
| 底の目安（washout） | 売られ尽くし3条件のそろい数（0〜3）：①50日線の上が 5%未満 ②150日線の上が 15%未満 ③SOXX が150日線から −20%以下。「いま売られ尽くしているか」だけを見るので、反発すると数が減る |
| 底の局面（washout.phase、v1.1） | そろい数が減った理由を区別する。起点＝今回最初に3条件がそろった日（3条件そろいの間隔が40営業日未満なら同じ局面）。最後にそろってから60営業日まで追う。判定の順：**底割れ**＝終値が起点の終値の −10%以下 → **売られ尽くし中**＝当日3条件そろい（一度外れた後なら **二番底を試し中（再点灯）**）→ **二番底を試し中**＝終値が起点の終値より下 → **回復を確認**＝起点以降に50日線の上が50%超の日があった → **反発中・二番底待ち**＝それ以外。60営業日を過ぎたら **該当なし** |
| 相対力の帯（strip） | SOXX ÷ 比較相手の RS線が EMA の上なら緑、下なら赤。比較相手は 市場（SPY）・テック全体（XLK）・ソフト（IGV）・ハード（AAPL・ANET・CSCO・DELL・HPE・SMCI・CIEN・GLW・APH・NTAP・HPQ の均等加重）。短期＝21日EMA、中期＝50日EMA。全部緑が3日続けば「半導体がテックの主役」、全部赤が3日続けば「主役ではない」、それ以外は前の状態を続ける |
| 分野別 | AI計算・製造／製造装置／メモリー／アナログ・汎用／光・後工程／設計ソフト ごとの 上昇中−下落中 と 50日線上の割合 |

簡易ステージは「150日線の向き」を条件にするため、長い上昇の直後の急落では下落中の割合が公式より小さく出る（2026-11-06：簡易 12%、公式 74%）。
公式が取れる日は公式を優先して読む。

## 2. 15年の検証（2011-01〜2026-11-06、SOXX 配当込み、週次 814週）

データ：`history` ブランチの `prices_max.csv.gz`（`history/fetch_history.py`、Yahoo period=max）。
**生存者バイアスあり**：中身は「今の銘柄」で過去を計算した（2011年初に履歴があるのは 51銘柄。倒産・買収された会社は入っていない）。
検証スクリプトはこのリポジトリに含めていない（作業用。再現は history ブランチのデータで可能）。

### 2.1 判定ラベル → その後の SOXX

| 判定 | 週数 | 13週後 平均 | 上昇した割合 | 13週以内に −15%超の下落 | 13週以内に −10%超 |
|---|---|---|---|---|---|
| 健全 | 353（43%） | +7.0% | 77% | **10%** | 19% |
| 改善中 | 44 | +7.8% | 75% | 5% | 16% |
| どちらとも | 89 | +4.9% | 61% | 12% | 25% |
| 悪化中 | 128 | +6.2% | 69% | **19%** | 34% |
| 弱い | 209（25%） | +6.2% | 66% | **21%** | 35% |
| 全期間 | 814 | +6.5% | 71% | 13% | ― |

→ 上がるか下がるかは当てない（平均はほぼ同じ）。**大きく下げる危険の高さ**を分ける物差し（健全 10% 対 弱い 21%）。

### 2.2 危険の目安（3条件のそろい数）→ 翌13週に −15%超の下落が来た割合

| そろい数 | 週数 | 発生率 | 2011〜2018 | 2019〜2026 |
|---|---|---|---|---|
| 0 | 413（51%） | **9%** | 6% | 12% |
| 1 | 144 | 10% | | |
| 2 | 101 | 17% | | |
| 3 | 156（19%） | **24%** | 12% | 39% |

19種類の指標（中身・伸びすぎ・ボラ・VIX・社債の質・市場比など）を単独で試しても、見分ける力（AUC）は最大 0.61 で、この3条件の数え上げと同程度。
19指標を組み合わせた機械学習（ロジスティック回帰・勾配ブースティング。前年までで学習→翌年を予測）は AUC 0.43〜0.52 で当てずっぽう以下。
**13週先の急落を事前に当てることは、この種の指標ではできない。** できるのは「今の危険度」を示すことと、天井の後に早く気づくこと。

### 2.4 底：売られ尽くし（washout）3条件のそろい数 → その後

「だまし」＝成立した日から60営業日以内に、終値がその日より10%以上下がった。

| そろい数 | 回数 | 13週後 | 26週後 | 52週後 | だまし | 60日内の最大下落（中央値／最悪） |
|---|---|---|---|---|---|---|
| 1つ以上 | 15 | +11% | +18% | ― | 40% | −9% ／ −24% |
| 2つ以上 | 12 | +12% | +21% | ― | 42% | −6% ／ −19% |
| **3つすべて** | **6** | **+24%** | **+40%** | +71% | **0%** | −4% ／ −9% |

3条件がそろった日：2011-08-08、2020-03-16、2022-06-13、2022-09-30、2025-04-03、**2026-11-05**（結果待ち）。
浅い底（2015年、2018年）は3条件では拾えない。2026-07-24 に出た1条件の合図は、その後 −35% のだましだった。
**「だまし0%」は60営業日・−10%という定義の上での数字**で、5回とも反発の後に起点の終値を一度割っている（2.4b）。レポートでは「外れなし」と書かない。

### 2.4b 3条件がそろった後の経過（過去5回。数字は起点＝最初にそろった日の SOXX 終値に対する比率、日数は営業日）

| 起点 | 3条件が外れるまで | 二番底（60日内の最安値） | その日のそろい数 | 回復の確認まで | 120日内の最安値 |
|---|---|---|---|---|---|
| 2011-08-08 | 1日 | 9日後、−1.5% | 3/3（再点灯） | 27日（+15%） | −1.5% |
| 2020-03-16 | 1日 | 4日後、−0.5% | 3/3（再点灯） | 20日（+30%） | −0.5% |
| 2022-06-13 | 1日 | 13日後、−8.1% | 2/3（2日後に再点灯） | 24日（+5%） | **−18.1%**（約4か月後） |
| 2022-09-30 | 1日 | 10日後、−6.3% | 3/3（再点灯） | 26日（+6%） | −6.3% |
| 2025-04-03 | 4日 | 3日後、−9.1% | 3/3（そろったまま） | 20日（+12%） | −9.1% |
| **まとめ** | 1〜4日 | **3〜13日後（平均8、中央値9）、−0.5〜−9.1%（中央値−6.3%）** | 5回中4回は当日3/3 | 20〜27日（中央値24） | |

- 3条件は反発ですぐ外れる（数が減るのは通常の動き）。その後、5回とも起点の終値を一度割り込んだ（二番底）。
- 二番底では3条件が再点灯するのが通例。再点灯せずに回復の確認まで進んだ例はない。
- 2022年6月だけは、回復の確認（7/19）の後に安値を更新した（9/26 に起点の −10% を割り、9/30 に次の3条件そろい）。利上げで悪材料が続いた局面。
  2020年・2025年型（そのまま回復）と2022年6月型を分けたのは、値動きではなく悪材料が続いたかどうか → レポートでは週次の「下側の条件」（WFE・DRAM価格・CapEx）と併せて読む。
- 底割れの線を −10% にしたのは、過去5回の最悪（−9.1%）を超える水準だから。
- 局面を15年で再生した結果（その局面に入った日の13週後。件数が少ないので参考）：売られ尽くし中 +24%（5回）、反発中・二番底待ち +18%（13回、上昇77%）、
  二番底を試し中（再点灯）+21%（8回、75%）、二番底を試し中（再点灯なし）+6%（10回、60%）、回復を確認 +8%（7回、71%）、底割れ 2回。

「底の確認」の工夫（20日線上が10日で2割→8割に急増、指数は安値更新なのに中身は改善、売られ尽くし後の21日EMA・10日高値回復）は、
だましが 27〜43% で、従来の「50日線上が半分超に戻る」（24%）より良くならなかった。確認を待っても精度は上がらず、底から +10% 高く買うだけ。
→ **浅い条件を捨て、深い条件の「そろい数」を出す。** 1〜2つは「底探しの入口（だまし約4割）」、3つは「過去5回とも26週後に上昇。ただし5回とも二番底を試した（2.4b）」と書き分ける。

回復の確認（50日線上>50%、帯が全部緑、30週線回復）は底から +15〜25% の時点で出て、そこから高値回復までの残りは中央値 +19〜24%。
長い下げ（2018年、2022年、2024〜25年）では途中で 5〜12回のだましが出た。

### 2.5 相対力の帯で乗り換えた場合（参考。採用しない）

| 2011〜2026 | 年率 | 最大下落 | シャープ |
|---|---|---|---|
| SOXX 持ちっぱなし | +22.9% | −46% | 0.82 |
| 帯（中期）全部緑→SOXX、全部赤→現金 | +14.2% | −40% | 0.69 |
| 帯（中期）全部緑→SOXX、全部赤→XLK | +21.0% | −44% | 0.83 |

切り替え 55回。2023年以降だけ持ちっぱなしに勝ち、2011〜2022年は全期間で負けた（2019〜2022年は退避中に SOXX が +78%）。
3年分（2024〜26年）だけの検証では年率 +43% 対 +25% と大きく勝って見えたが、直近に合っていただけ。**帯は表示にとどめる。**

退避先の検討（2026-11-09）：株のセクターで半導体と逆に動くものはなかった（週次相関が負なのはドル −0.13 だけ）。
半導体と関係なく動くのは生活必需品（0.00）・公益（+0.08）・ヘルスケア・金・米長期国債。2026年だけは ごみ処理・保険ブローカー・給与計算・医薬品卸が −0.3〜−0.5 だが、2024〜25年はほぼ0。この検討は一旦保留。

## 3. プロンプトでの扱い

- 日次 0節「セクターの状態」：判定ラベル（言葉→数字）、危険の目安（n/3 と過去の発生率）、底の目安（n/3）、帯（短期・中期の2行×4段とそろってからの日数）、分野別、公式ステージ（market-data から転記：SOXX・SMH の細区分、監視：半導体 のステージ分布とラベル）。
- 週次 4d節：同じ項目の週次版と前回比。引継ぎ YAML に `SECTOR_HEALTH`。
- 変化点（build_signals.py）：`health_label_change`、`risk_count_change`、`washout_count_change`、`rs_strip_state_change`。1節のシグナルに出るので 0節では再掲しない。
- 変化点 `washout_phase_change`（v1.1）：底の局面が変わった日。
- 禁止：帯・危険の目安・底の目安を売買の合図と書くこと。帯の「主役ではない」を「売り」と書くこと。底の目安の「3つ」や局面の「反発中」「回復を確認」を「底の確定」と書くこと。「過去5回で外れなし」「だまし0%」と書くこと。二番底の時期（過去の範囲）を予測として書くこと。
