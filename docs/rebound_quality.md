# 戻りの質（rebound_quality.json）

追補 R1（2026-11-10）。計算は `build_rebound.py`（version 1.1。1.1＝文の基準を「50日平均の○倍」に統一。値と定義は 1.0 と同じ）。日次 2節の「戻りの質」で使う。採点（S/D・A〜X）・シグナル・週次の判定には入れない。

## 1. 何を見るのか

大きく下げた後の上げには2種類ある。

- **買い戻しが中心の上げ**：売りすぎた人が買い戻すだけ。売り物が出ないので値段は上がるが、売買代金は増えない。いちばん売られた銘柄がいちばん上がる。
- **新しい買いが入った上げ**：下げた日と同じか、それ以上の売買代金を伴う。強かった銘柄が先頭に立つ。

どちらかを断定する道具ではない。「今日の上げはどちらの形に近かったか」を、同じ物差しで毎日書くためのもの。
底の局面（売られ尽くした後に二番底を試すか）は `sector_health.json` の `washout.phase`（日次 0節）が持つので、こちらには入れていない。

## 2. 出している数字

| 項目 | 中身 | 読み方 |
|---|---|---|
| 指数3本（S&P500・QQQ・SOX） | 前日比、売買代金の比（直前50営業日の平均／直前5営業日の平均／投げ売りの日）、下げ幅のうち戻した割合 | 上げたのに売買代金が投げ売りの日よりずっと少ない＝売り物が出なかった上げ |
| 半導体（約40銘柄） | 上げ・下げの数、売買代金が50日平均より少ないまま上げた数、1.5倍以上で上げた数、合計の売買代金の比 | 「全面高」でも、少ない売買代金で上げた銘柄が多ければ中身は細い |
| 売買代金の偏り | 売買代金が最大の1銘柄の割合と、それを除いた合計の比 | 1銘柄の材料（例：NVDAの急落）で合計が膨らんで見えるのを外す |
| 主役 | 直前20営業日の騰落率（前日まで）と今日の騰落率の順位相関、下位・上位3分の1の今日の平均 | 順位相関が−0.3以下で上げた日＝「売られた銘柄ほど上げた」 |
| メモリー（米国5銘柄） | 銘柄ごとの前日比と売買代金の比 | |
| レバレッジETF | SOXL・SOXS の売買代金と手元の期間での順位、（SOXL＋SOXS）÷SOXX | 高いほど短期の値幅取りが多い。両方が膨らむ日は荒れやすい |

- 売買代金＝終値×出来高。S&P500（^GSPC）と SOX（^SOX）は指数に出来高がないので、**SPY と SOXX の売買代金で代用**する（JSON の `volume_ticker`）。
- 投げ売りの日＝直近10営業日（当日を除く）で SOXX が最も下げた日。その下げが−4%より浅ければ「なし」（`context.selloff_day` が null）。
- 下げ幅のうち戻した割合＝（いま−安値）÷（高値−安値）。高値は直近252営業日の終値の最大、安値はその後の終値の最小。
- 調整局面（`context.in_correction`）＝SOXX が高値から−10%以下。日次はこの間だけ表を出す。
- 言葉（`volume_word`）：50日平均比 0.8未満＝少ない、1.2超＝多い、その間＝平均並み。文には必ず「50日平均の○倍」と基準を書く（日次の表の出来高比は20日平均が基準で、別の数字になる。「普段の○倍」とだけ書かない）。

## 3. 例（2026-11-09。SOXX +7.5%、全面高の日）

- 指数：S&P500 +2.35%（売買代金は50日平均の1.08倍、5日平均の0.75倍）、QQQ +3.54%（1.31倍、0.78倍）、SOX +6.85%（1.28倍、0.80倍）
- 投げ売りの日（11/5）と比べた売買代金：S&P500 0.40倍、QQQ 0.44倍、SOX 0.65倍
- 下げ幅のうち戻した割合：S&P500 42%、QQQ 29%、SOX 18%
- 半導体42銘柄：上げ41・下げ1。上げた41のうち18は売買代金が50日平均より少なく、12は1.5倍以上。合計は5日平均の1.19倍だが、NVDA（急落で売買代金が50日平均の3.2倍）が35%を占め、除くと0.92倍
- 主役：売られた銘柄ほど上げた（下位3分の1は+10.0%、上位3分の1は+5.7%、順位相関−0.50）
- メモリー：5銘柄すべて売買代金が50日平均より少ないまま上昇（MU 0.89倍、SNDK 0.83倍、WDC 0.73倍）

読み：「買い戻しが中心の上げ」の形に近い。対照として、2026-03-31（その後20営業日で SOXX +37%）は SOX +6.2%で売買代金が投げ売りの日の1.38倍、S&P500 は1.59倍だった。ただし下の検証のとおり、1〜2例で型を決めてはいけない。

## 4. 検証（手元の約3年、2026-11-10 実施）

対象：SOXX が高値から10%以上下げた局面で、1日+4%以上上げた18回（2024-07〜2026-09）。それぞれの日の指標と、その後の SOXX の5営業日後・20営業日後の騰落率、20営業日以内の最安値との順位相関を見た。

| 指標 | 5日後 | 20日後 | 20日以内の最安値 |
|---|---:|---:|---:|
| S&P500（SPY）の売買代金÷50日平均 | +0.06 | +0.03 | +0.18 |
| QQQ の売買代金÷50日平均 | −0.01 | −0.26 | −0.01 |
| SOX（SOXX）の売買代金÷50日平均 | +0.06 | +0.21 | −0.02 |
| SOX（SOXX）の売買代金÷5日平均 | −0.19 | **+0.56** | +0.21 |
| SOX の売買代金÷投げ売りの日 | −0.09 | +0.16 | +0.11 |
| S&P500（SPY）の売買代金÷投げ売りの日 | −0.16 | −0.01 | +0.02 |
| 売買代金が50日平均より少ないまま上げた銘柄数 | +0.01 | +0.02 | +0.05 |
| 1.5倍以上で上げた銘柄数 | −0.02 | −0.10 | −0.10 |
| 売られた銘柄ほど上げたか（順位相関） | **+0.47** | +0.02 | +0.11 |
| 下げ幅のうち戻した割合 | +0.15 | −0.24 | −0.12 |

- ほとんどの指標は、その後の値動きと関係がなかった（±0.3以内）。
- 関係が見えたのは2つ：SOXX の売買代金が5日平均より多い日ほど20日後が良い（+0.56）、売られた銘柄ほど上げた日ほど5日後が悪い（+0.47）。
  ただし10指標×3期間＝30通りを試した中の2つで、18回しかないので偶然の範囲を出ない。**合図や採点には使わない。**
- 同じ18回のうち10回は、20営業日以内にその日の終値を5%以上下回った。「下落局面の大幅高は、その日の終値を一度は割ることが多い」という一般的な傾向で、
  これは 0節の底の局面（15年、過去5回とも二番底）と同じ向きの事実。
- 次の検証の候補：`history` ブランチの15年データで同じ表を作り直す（SOXX÷5日平均と順位相関の2つが残るかどうか）。それまでは描写専用。

## 5. 書き方の約束

- 「買い戻しが中心の形」「売り物が出なかった上げ」は描写。「だから下がる」「戻り売り」とは書かない。
- 「出来高を伴って全面高」と書くのは、半導体の上げた銘柄のうち1.5倍以上が半分を超え、かつ最大の1銘柄を除いた合計が5日平均を上回る日だけ。
  それ以外は「全面高だが売買代金は○○」と数字で書く。
- S&P500 と SOX の売買代金は SPY・SOXX の代用であることを、表の見出しか注に必ず書く。
- `rebound_quality.json` の値を再計算・上書きしない。`us_as_of` が日次の基準日と違う日は「戻りの質：未取得」の1行。

## 6. 補完（過去日の作り直し）

`python build_rebound.py --out <data ブランチのコピー> --as-of YYYY-MM-DD`（ほかの build_*.py と同じ。data ブランチには書かない）。
履歴は `history_rebound.csv`（1日1行。指数3本の前日比・売買代金の比・戻した割合、半導体の上げた数・少ない売買代金で上げた数・順位相関）。
