## 0. 書き方の約束

1. 状態を表す語は「言葉」で書き、数字と記号を括弧で後ろに付ける。例：「半導体の値動きは弱い（Sスコア 23.8）」「SOXの向きは普通（S1＝0、前回+1）」。
   記号は消さない（前回との比較、levels.json との照合に使う）。記号だけ・英語だけの行を作らない。
2. 冒頭ブロック（レポートの先頭。SendUserMessage の要約も同じ文で始める）：
   ## 今日のひとこと
   - 半導体：〔言葉〕（記号）。週次は「株価は○○（値動きの点数）／市況の見方は○○（総合点、帯）」と分けて書く（v1.3。どちらを先に書くかは prompts/judge/a_opening.md）
   - メモリー：〔言葉〕（記号）。同じ形
   - 行動の目安：〔条件つきで1行。「買え」「売れ」とは書かず、水準と条件で〕
   ## なぜその判断か（3〜5行）
   - 根拠を1行ずつ「言葉 → 数字（記号）」。押し上げた要因と抑えた要因を分ける
   - 最後の1行は「見方が変わる条件」を数値で（週次は THESIS_INVALIDATION と TOP_UPSIDE／DOWNSIDE_TRIGGER から、日次は直近の週次のそれを転記）
3. 本文の表には「言葉」の列を置くか、数字の横に言葉を添える。引継ぎYAML（# SEMI_HANDOFF）は機械が読むので記号のまま。
4. 巻末に「読み方」：そのレポートで使った記号だけを1行ずつ。
5. （v1.3）倍率には必ず基準を書く。出来高比は「20日平均の○倍」、戻りの質（rebound_quality.json）の売買代金は「50日平均の○倍」。「普段の○倍」とだけ書かない。
6. （v1.3）騰落率・出来高・高値からの下落率は data ブランチの値だけを書く（記事の数字は書かない）。同じ銘柄の同じ指標に2通りの数字を書かない。

## 1. 段階とスコアの言葉（5段階で統一）

| 段階（−2〜+2） | スコア（0〜100） | 言葉 |
|---|---|---|
| +2 | 75〜100 | 強い |
| +1 | 60〜74 | やや強い |
| 0 | 45〜59 | 普通 |
| −1 | 30〜44 | やや弱い |
| −2 | 0〜29 | 弱い |

総合点のラベル（強気／やや強気／中立／慎重／弱気）はそのまま使い、点数と帯を括弧に（例「やや強気（総合68点、±5）」）。v1.3：ラベルは「市況の見方」であることを添えて書く（「市況の見方はやや強気（総合68点、±5）」）。総合点は値動きの比重が10%なので、株価の状態（S・D・TECHNICAL の言葉）と必ず並べ、ラベルだけを見出しにしない。
前回比は「やや強い→普通（S1 +1→0）」のように言葉を矢印でつなぐ。
MとDが20点以上離れた「価格との不一致」は「市況は良いのに株価は弱い（M 71／D 18）」のように両方の言葉で書く。

## 5. 「行動の目安」の言い方（週次ビューと値動きから）

- 強気／やや強気 ＋ 値動きが普通以上：押し目での段階買いの条件（水準）を1行
- 強気／やや強気 ＋ 値動きが弱い：「市況は良いが株価は弱い。値動きの回復（例：SOXがSMA200回復、Sスコア45以上）を待つ」
- 中立：「様子見。上げ・下げの引き金（TRIGGER）の条件を確認」
- 慎重／弱気：「新規は見送り。下げの引き金と前提が崩れる条件（水準）を確認」
- 反転リスクが「発動」の項目がある：その項目を先に書く
- 日次：スコア・ビューは変えないので、「直近の週次は〇〇。今日の値動きは〇〇」と、週次の行動の目安を転記し、今日のシグナルで変わった水準だけ更新する

## 6. 「セクターの状態」の語（sector_health.json。日次 0節・週次 4d節）

| 記号・項目 | 言葉 |
|---|---|
| 判定ラベル healthy／improving／neutral／deteriorating／weak | 半導体の中身は 健全／改善中／どちらとも言えない／悪化中／弱い |
| stage2／stage4（簡易） | 「線の上で上向き」の銘柄の割合／「線の下で下向き」の銘柄の割合（v1.3：「上昇中」「下落中」とは書かない。公式ステージの「上昇（2）」「下落（4）」と数え方が違い、同じ日に 74% と 15% のように離れるため）。分母は監視する半導体42銘柄（30週線のある銘柄）。線の上で上向き＝株価が30週線（150日線）の上で線も4週前より上向き、線の下で下向き＝株価が線の下で線も下向き、残りは中間。長い上昇の直後の急落では線がまだ上向きなので「線の下で下向き」が少なく出る（公式＝米国株側のステージ分布を先に書く） |
| above20／above50／above150 | 20日線／50日線／30週線（150日線）の上にいる銘柄の割合 |
| net_2_minus_4 | 「線の上で上向き」から「線の下で下向き」を引いた差（プラス＝上向きが多い） |
| risk.count n/3 | 大きく下げる危険の目安（3条件のうち n 個成立）。「翌13週に−15%超の下落が来た割合は過去15年で ○%」を必ず添える（0個 9%、1個 10%、2個 17%、3個 24%） |
| washout.count n/3 | 底の目安（売られ尽くし3条件のうち n 個成立）。「いま売られ尽くしているか」だけを見るので、反発すると減る（減った理由は底の局面で書き分ける）。1〜2個＝底探しの入口（だまし約4割）、3個＝過去5回とも26週後に上昇したが、5回とも二番底を試した |
| washout.phase（底の局面） | 売られ尽くし中（3条件がそろっている）／反発中・二番底待ち（そろった後に反発。起点の終値より上）／二番底を試し中（起点の終値を下回った。3条件が再びそろえば「再点灯」）／底割れ（起点の−10%を割った。過去の型より深い）／回復を確認（50日線の上が半分超）／該当なし（直近60営業日に3条件そろいなし＝まだ売られ尽くしていない） |
| 起点（anchor） | 今回の売られ尽くしで最初に3条件がそろった日。その日のSOXX終値が「二番底の線」、その−10%が「底割れの線」 |
| 二番底 | 売られ尽くしの反発の後、もう一度安値を試す動き。過去5回は起点から3〜13営業日後（平均8）、起点の終値から−0.5〜−9.1% |
| strip（帯） 緑／赤 | 相対力の帯。比較相手（市場・テック全体・ソフト・ハード）より強い（緑）／弱い（赤）。短期＝約1か月、中期＝約2か月半 |
| strip.state 主役／主役ではない | 4段が全部緑3日＝「半導体がテックの主役」／全部赤3日＝「主役ではない」。描写であって売買の合図ではない |
| subsectors | 分野別（AI計算・製造／製造装置／メモリー／アナログ・汎用／光・後工程／設計ソフト）の「線の上で上向き」−「線の下で下向き」 |

書き方の例：「公式ステージでは半導体38銘柄の74%が下落（ステージ4）。機械判定は悪化中（線の上で上向き 5%、線の下で下向き 12%、50日線の上 10%）。大きく下げる危険の目安は3つとも成立（risk 3/3、過去の発生率 24%）。
底の目安は1つ（washout 1/3）だが、11/5に3つそろった後の反発中・二番底待ち（起点 SOXX 131.90 から+11.3%、2営業日目。二番底の線 131.90、底割れの線 118.71。過去は起点から3〜13営業日後に二番底）。帯は短期・中期とも4段全部赤（中期は20日連続、7/17から『主役ではない』）」
