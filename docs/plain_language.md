# 半導体・メモリー定点観測｜やさしい表記の対応表（plain_language v1.0）

作成 2026-11-01。日次（daily.md）・週次（judge.md）の両方で使う。採点の定義・閾値はここでは変えない。変えるのは「書き方」だけ。
市場全体・個別銘柄・セクター内の語（レジーム、IX、BR、FB1、RSライン、リーダー／ラガード、調整耐性、ステージ等）は
米国株側の対応表 `https://raw.githubusercontent.com/bakaho19920625-wq/market-data/main/05_Plain_Language_Glossary.txt` を使う（同じ言葉にそろえる）。

## 0. 書き方の約束

1. 状態を表す語は「言葉」で書き、数字と記号を括弧で後ろに付ける。例：「半導体の値動きは弱い（Sスコア 23.8）」「SOXの向きは普通（S1＝0、前回+1）」。
   記号は消さない（前回との比較、levels.json との照合に使う）。記号だけ・英語だけの行を作らない。
2. 冒頭ブロック（レポートの先頭。SendUserMessage の要約も同じ文で始める）：
   ## 今日のひとこと
   - 半導体：〔言葉〕（記号）
   - メモリー：〔言葉〕（記号）
   - 行動の目安：〔条件つきで1行。「買え」「売れ」とは書かず、水準と条件で〕
   ## なぜその判断か（3〜5行）
   - 根拠を1行ずつ「言葉 → 数字（記号）」。押し上げた要因と抑えた要因を分ける
   - 最後の1行は「見方が変わる条件」を数値で（週次は THESIS_INVALIDATION と TOP_UPSIDE／DOWNSIDE_TRIGGER から、日次は直近の週次のそれを転記）
3. 本文の表には「言葉」の列を置くか、数字の横に言葉を添える。引継ぎYAML（# SEMI_HANDOFF）は機械が読むので記号のまま。
4. 巻末に「読み方」：そのレポートで使った記号だけを1行ずつ。

## 1. 段階とスコアの言葉（5段階で統一）

| 段階（−2〜+2） | スコア（0〜100） | 言葉 |
|---|---|---|
| +2 | 75〜100 | 強い |
| +1 | 60〜74 | やや強い |
| 0 | 45〜59 | 普通 |
| −1 | 30〜44 | やや弱い |
| −2 | 0〜29 | 弱い |

総合点のラベル（強気／やや強気／中立／慎重／弱気）はそのまま使い、点数と帯を括弧に（例「やや強気（総合68点、±5）」）。
前回比は「やや強い→普通（S1 +1→0）」のように言葉を矢印でつなぐ。
MとDが20点以上離れた「価格との不一致」は「市況は良いのに株価は弱い（M 71／D 18）」のように両方の言葉で書く。

## 3. 判定・予測・リスクの語

| 記号 | 言葉 |
|---|---|
| VIEW 半導体／メモリー | 半導体の見方／メモリーの見方 |
| THESIS_INVALIDATION | この前提が崩れたら見方を変える条件 |
| TOP_UPSIDE_TRIGGER／TOP_DOWNSIDE_TRIGGER | 上げの引き金／下げの引き金 |
| 反転リスク 未発動／警戒／発動 | まだ起きていない／兆候あり／起きた |
| 「テック内部の崩れ・ブレイクが伸びない地合い」（market-data由来） | 米国株側で、IT銘柄の多くが崩れ、高値を抜けても続かない地合い |
| 先導セクター（leadership、market-data由来） | 市場を引っ張っている業種と、半導体・テクノロジーの先導株の数（4週前比）。半分以下なら「置いていかれている」 |
| ヘッジ条件（hedge、market-data由来） | 米国株側で指数ヘッジを検討できる地合いか、今日その条件がそろったか。半導体の売買指示ではない |
| 長期SPY配分モデル（spy_model、market-data由来） | 長く持つ分の目安（5項目×20%）。buy＝持ち続け、sell＝減らす |
| シナリオ 強気／基本／弱気（確率） | 良いほうに転ぶ／このまま／悪いほうに転ぶ（確率） |
| 予測 hit／miss／void | 当たり／外れ／判定できず |
| Brier | 予測の精度（0が満点、1が最低） |
| TRACK_RECORD | これまでの的中率 |
| 確信度 A／B／C／D | 根拠の強さ：複数の一次情報／一次情報あり／二次情報中心／推測・単一報道 |
| R1〜R14 | 判定の約束ごと（番号のまま。本文では内容を言葉で） |
| SIGNALS（HBM、COMMODITY_DRAM 等） | 製品別の状態（HBM＝AI向け高帯域メモリー、commodity＝汎用品、legacy＝旧世代品） |
| 導入段階 0〜5 | 構想／標準化／試作／顧客認定／量産／重要売上 |

## 5. 「行動の目安」の言い方（週次ビューと値動きから）

- 強気／やや強気 ＋ 値動きが普通以上：押し目での段階買いの条件（水準）を1行
- 強気／やや強気 ＋ 値動きが弱い：「市況は良いが株価は弱い。値動きの回復（例：SOXがSMA200回復、Sスコア45以上）を待つ」
- 中立：「様子見。上げ・下げの引き金（TRIGGER）の条件を確認」
- 慎重／弱気：「新規は見送り。下げの引き金と前提が崩れる条件（水準）を確認」
- 反転リスクが「発動」の項目がある：その項目を先に書く
- 日次：スコア・ビューは変えないので、「直近の週次は〇〇。今日の値動きは〇〇」と、週次の行動の目安を転記し、今日のシグナルで変わった水準だけ更新する
